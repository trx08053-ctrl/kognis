# Маршруты и доступ (подробно — docs/SECURITY.md)
- Маршрут закрыт по умолчанию; публичный — только строкой в `security/public-routes.txt` (решение человека).
- Данные — с фильтром по владельцу в запросе к БД; чужой объект → 404.
- На каждый маршрут с `{id}` — тест `@pytest.mark.security("idor", "<METHOD> <path>")`: пользователь B → 404.
- Списки — только страницами (`limit` ≤ 100); ошибки внешних сервисов называют причину, без секретов.
