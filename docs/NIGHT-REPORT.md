## Как открыть
```bash
cd ~/src/kognis && just dev          # http://192.168.2.155:8000 — открывается и с Mac по сети
```
Настройки для разработки — `.deploy/dev.app.env` (уже создан: `KOGNIS_ENV=dev`, ключ данных для записей
«под замком»). Staging в Docker: `just stage` (настройки — `.deploy/staging.app.env`, ключ уже создан).
