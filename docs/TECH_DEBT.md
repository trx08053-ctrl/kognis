# Технический долг

Каждый осознанный компромисс записывается сюда со ссылкой на задачу `bd`.

| ID | Где | Что не так | Почему так | Риск | Задача |
|---|---|---|---|---|---|
| TD-1 | users/web (вход) | нет ограничения попыток входа | отдельная задача hardening, ADR 0003 | перебор паролей | kognis-yaj |
| TD-2 | diary | дата записи по UTC сервера, а не локальная дата пользователя (D4/D11) | часовой пояс профиля — позже | запись вечером попадает не в тот день | kognis-7cn |
| TD-3 | users | просроченные сессии не удаляются | не критично на старте | рост таблицы `sessions` | kognis-yaj |
| TD-4 | safety/web | кризисный сигнал ищется только в записи (текст, теги, эмоции), не в рефлексии «Итога дня»; список фраз намеренно небольшой (без ИИ), возможны пропуски | границы kognis-d5q; список растёт по примерам | пропуск сигнала | см. bd |
