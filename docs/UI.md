# Интерфейс: как менять и проверять

Читать, когда задача меняет интерфейс (AGENTS.md → «Прочитай, когда…»).

- **Смотри своими глазами:** `just dev` → `just shot /путь` → открой PNG из `.evidence/screens/` и оцени вид,
  прежде чем считать правку сделанной. Для обеих тем (светлой и тёмной) и узкого экрана, если они затронуты.
- **Сценарии в браузере:** `just e2e` (Playwright); селекторы — по подписям и `data-testid`, не по классам.
  Доступность — axe в e2e: нет нарушений serious/critical.
- **Код UI** — только TypeScript без `any`; `just fe-check` (Biome, tsc strict, vitest, сборка).
- **Типы ответов API** — только из `frontend/src/api.gen.ts` (`components["schemas"]["…"]`). Поменял схемы
  FastAPI — `just api-types`, затем исправь то, что сломал `tsc` (проверка `contract`).
- **Замечания человека кликом** (`tasks/<id>/ui-feedback.md`, `just ui-feedback`): для каждого `open` — найти
  элемент по селектору, исправить, проверить на странице, сменить статус на `done` и дописать
  «- **Сделано:** …». С открытыми замечаниями задача не закроется.
