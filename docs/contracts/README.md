# Контракты

Публичные интерфейсы системы, от которых зависят другие: HTTP API (OpenAPI), события и сообщения
(JSON Schema / AsyncAPI), форматы файлов и конфигурации, CLI.

Правила:
- контракт описывается машиночитаемо (`*.yaml` / `*.json`) и проверяется тестами (Schemathesis для
  OpenAPI, валидация JSON Schema);
- ломающее изменение — только через ADR и с решения человека; совместимость N-1, deprecation ≥ 1 минорный релиз;
- ссылки на реализацию — в формате `` `src/<pkg>/…/file.py::symbol` `` (проверяет `just check refs`).
