## Бизнес-правила
- Функции — перечисление `Feature` (`src/kognis/access/_domain.py::Feature`); неизвестная функция — ошибка,
  а не молчаливое «да».
- `can_use(user_id, feature)` — единая точка проверки; `web` вызывает её для ИИ-анализа.
