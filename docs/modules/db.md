# Модуль `db`

> Публичные символы и зависимости — `just context db`.

- **Назначение:** платформа данных — подключение (DATABASE_URL), общий `metadata`, транзакции. Своих таблиц нет.
- **Публичный API:** `src/kognis/db/__init__.py` — `make_engine`, `transaction`, `metadata`, `database_url`.
- **Термины и синонимы:** база данных, подключение, транзакция, таблица, database, session, engine, metadata.

## Бизнес-правила
- таблицы объявляют модули-владельцы в своих `_infra.py`; схему меняют только миграции Alembic.
