# Модуль `gameplay`

> Ссылки на код — `` `src/<пакет>/<модуль>/<файл>.py::<символ>` `` (проверяет `just check refs`).
> Публичные символы и фактические зависимости генерируются: `just context gameplay` / `docs/MAP.md`.

- **Назначение:** считает опыт, уровень, серию дней и достижения пользователя (правила D8 как данные); не знает о
  дневнике — действия ему передаёт слой `web` (D2). Квесты и квизы — отдельные задачи.
- **Публичный API:** только `src/kognis/gameplay/__init__.py` (`__all__`); файлы `_*.py` — внутренности.

## Бизнес-правила
- Запись: +10 XP, но не более трёх записей в день (`src/kognis/gameplay/_domain.py::entry_xp`); за одну запись —
  один раз. Запись сверх лимита пишется с 0 XP: день всё равно активен для серии.
- Итог дня: +20 XP, один раз за дату (повторное сохранение XP не даёт).
- Опыт и серия начисляются только за дни от «сегодня − 7» до «сегодня» (`is_rewardable_day`): будущие и давние
  даты копить нельзя; записи за них сохраняются, но XP не дают.
- Достижение выдаётся через savepoint: параллельный запрос не роняет транзакцию и не теряет запись дневника.
- Кризисная запись (safety) опыта и серии не даёт — `web` не вызывает начисление.
- Уровень — по таблице порогов `LEVEL_THRESHOLDS` (1 → 0, 2 → 50, 3 → 120 …); после таблицы каждый следующий
  уровень +300 XP (`level_for`, `level_start`).
- Серия — подряд идущие даты с записью или итогом дня, даты локальные (D11), «сегодня» передаёт `web`
  (`streak_length`). Пропуск ровно одного дня гасится заморозкой — одна на ISO-неделю пропущенного дня; иначе
  серия сбрасывается. Заморозка серию не удлиняет. Серия жива, пока с последней активности ≤ 1 дня (или 2, если
  заморозка ещё доступна).
- Достижения (данные `ACHIEVEMENTS`): первая запись, серия 3/7/30 дней, 10 итогов дня. Выдаются один раз
  (уникальность в БД), с датой получения (локальная дата пользователя на момент начисления).

## Данные (владение)
| Сущность / таблица | Владелец | Кто ещё читает | Кто может изменять |
|---|---|---|---|
| `xp_events` (событие опыта: вид, источник, день, XP; уникально по владельцу+виду+источнику) | `gameplay` | — | только `gameplay` |
| `achievements` (код, дата получения; уникально по владельцу+коду) | `gameplay` | — | только `gameplay` |

Серия и уровень не хранятся — вычисляются из `xp_events`.

## Внешние зависимости
