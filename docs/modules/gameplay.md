# Модуль `gameplay`

> Ссылки на код — `` `src/<пакет>/<модуль>/<файл>.py::<символ>` `` (проверяет `just check refs`).
> Публичные символы и фактические зависимости генерируются: `just context gameplay` / `docs/MAP.md`.

- **Назначение:** считает опыт, уровень, серию дней и достижения пользователя (правила D8 как данные); не знает о
  дневнике и анализе — действия и идеи квестов ему передаёт слой `web` (D2). Есть квесты, челленджи и квизы-рефлексии.
- **Публичный API:** только `src/kognis/gameplay/__init__.py` (`__all__`); файлы `_*.py` — внутренности.

## Бизнес-правила
- Запись: +10 XP, но не более трёх записей в день (`src/kognis/gameplay/_domain.py::entry_xp`); за одну запись —
  один раз. Запись сверх лимита пишется с 0 XP: день всё равно активен для серии.
- Итог дня: +15 XP, один раз за дату (повторное сохранение XP не даёт).
- Баланс опыта (kognis-0a8, правила — данные в `src/kognis/gameplay/_domain.py`): ответ на уточняющие вопросы
  разбора +10 (один раз на разбор, `award_analysis_answer`); бонус рефлексии 5 XP за каждую отметку
  (`step` — маленький шаг, `good` — хорошее, `reframe` — переформулировка, `insight` — инсайт), 5–15, один раз
  на запись или итог дня (`reflection_bonus`); отметки ставит сам пользователь — текст не анализируется,
  длина и тон не влияют. Дневной потолок 60 XP на запись, итог, ответ разбора и рефлексию (`capped_xp`);
  источник сверх потолка записывается с 0 XP. Квесты, квизы и бонус недели в потолок не входят.
  Кризисный разбор и кризисная запись игровой механики не запускают.
- Опыт и серия начисляются только за дни от «сегодня − 7» до «сегодня» (`is_rewardable_day`): будущие и давние
  даты копить нельзя; записи за них сохраняются, но XP не дают.
- Достижение выдаётся через savepoint: параллельный запрос не роняет транзакцию и не теряет запись дневника.
- Кризисная запись (safety) опыта и серии не даёт — `web` не вызывает начисление.
- Уровень — по таблице порогов `LEVEL_THRESHOLDS` (1 → 0, 2 → 50, 3 → 120 …); после таблицы каждый следующий
  уровень +300 XP (`level_for`, `level_start`).
- Серия «Нить» (kognis-3r1, [ADR 0006](../adr/0006-motivation-2.md)) — подряд идущие даты с записью или итогом дня,
  даты локальные (D11), «сегодня» передаёт `web` (`src/kognis/gameplay/_streak.py::streak_state`). Запас заморозок
  до 2 (у нового пользователя 2, +1 за каждые 7 активных дней); каждый пропущенный день тратит одну заморозку
  автоматически, нечем закрыть — обрыв. Выходные дни (0–2 дня недели по выбору) не рвут серию и не продлевают её;
  заморозка тоже серию не удлиняет. Восстановление: в течение 72 часов (3 локальных дня после первого
  пропущенного) обрыв серии ≥ 2 дней возвращается короткой записью «что помешало» — одна на обрыв, XP не даёт
  (`recoverable_break`, `POST /api/progress/recovery`). Прежнее правило (одна заморозка на ISO-неделю,
  `streak_length`) действует только до `rules_from` существующих пользователей — их серии не уменьшаются.
- Недельная цель: 3/5/7 активных дней в ISO-неделю (по умолчанию 3, `PUT /api/progress/settings`); выполнение
  даёт +30 XP один раз за неделю (событие `weekly_goal`), невыполнение ничем не наказывается.
- Экран прогресса: главное — «дней с дневником за 30» и «всего дней»; оборванная серия не показывается как «0» —
  вместо неё предложение восстановления.
- Достижения выдаются один раз (уникальность в БД), с датой получения (локальная дата пользователя на момент
  начисления). Прежние (данные `ACHIEVEMENTS`): первая запись, серия 3/7/30 дней, 10 итогов дня — остаются.
- Достижения по категориям (kognis-0a8, `src/kognis/gameplay/_achievements.py`, 4 × 3 уровня — код
  `<категория>_<1|2|3>`: бронза/серебро/золото): «Постоянство» — дней с дневником 7/30/100 (не подряд);
  «Глубина» — рефлексий с отметкой «шаг» или «инсайт» 5/25/100; «Исследователь» — разные направления
  разборов плюс разные квизы 2/4/все (5 направлений + 3 квиза); «Забота о себе» — выполненных шагов квестов
  5/25/100. Скрытые тёплые (`?` до получения): `comeback` — возвращение после паузы больше 7 дней,
  `first_gratitude` — первая отметка «хорошее», `year_diary` — дневнику год. За грусть и объём текста
  достижений нет. Миграция 0017: «серия 7» даёт бронзу «Постоянства», «серия 30» — бронзу и серебро.
  `GET /api/progress` отдаёт сетку (`categories`, `hidden`) с прогрессом до следующего уровня.

## Квесты, челленджи, квизы (kognis-99x)
- Библиотека — данные `QUESTS` (6 шт.: 4 квеста и 2 челленджа) и `QUIZZES` в `src/kognis/gameplay/_quests.py`.
  Квест из анализа: `web` берёт идею из результата анализа, `QuestService.accept_idea` делает из неё 3 шага; одна
  идея — один квест. Квест из библиотеки повторно принимается после завершения предыдущего (иначе 409).
- Шаг: +15 XP один раз (повторная отметка XP не даёт), завершение квеста (все шаги) +50 XP.
  Шаг челленджа — не чаще одного в день (иначе 409).
- Квиз-рефлексия: по одному ответу на каждый вопрос, ответы сохраняются, +10 XP, не чаще одного раза в день на
  квиз (повтор → 409). Ответы с кризисными сигналами (safety) сохраняются, но XP не дают и возвращают блок помощи.
- XP за квесты и квизы серию дней не продлевает: серия считается только по записям и итогам дня (`STREAK_KINDS`).
- Опыт — события `xp_events` видов `quest_step`, `quest`, `quiz`; квест другого пользователя — 404.

## Цифровые герои (kognis-zjg)
- Спутник: облик, имя и обращение «ты/вы» выбирает пользователь (`PUT /api/companion`). Стадия 1…5 — по числу дней
  с дневником (0/7/21/45/90, `src/kognis/gameplay/_heroes.py::companion_stage`), не по серии; не убывает, при
  паузе спутник «отдыхает» (`is_resting`), ничего не отнимается.
- Открытка: после итога дня спутник «путешествует»; при следующем входе приходит одна открытка в день
  (`HeroService.state`, выбор детерминирован `pick_postcard`); текст — из словаря интерфейса, без ИИ.
- Наставники (Аналитик — КПТ, Проводник — ACT, Садовник — позитивная, Механик — активация) открываются разбором
  направления или квестом библиотеки этого направления (`unlocked_mentors`).
- Одна реплика спутника на экран по ситуации (`choose_line`): новая стадия, возвращение, итог дня, мягкое о
  серии; тексты — словарь `hero.*`. При кризисном флаге на экране интерфейс героев не показывает.
