## 1. Цель
Современный понятный интерфейс: тёмная тема, простой режим по умолчанию и Advanced для опытных, главная страница с состоянием дня.

## 2. Границы
- **Входит:** навигация и раскладка, тёмная тема (системная + переключатель), переключатель Advanced (настройка профиля на сервере), главная: итог дня, серия, уровень, последние записи; Advanced: графики настроения/самочувствия (Recharts), фильтры записей по тегам/эмоциям/датам; онбординг с дисклеймером; скриншоты ключевых экранов в светлой и тёмной теме.
- **Не входит:** мобильное приложение.

## 2a. Область влияния
- **Модули:** frontend, users (настройки), web · **Данные:** настройки пользователя (режим, часовой пояс)
- **Что может сломаться:** вход и записи (U1), изоляция данных пользователей — регрессионные тесты должны остаться зелёными
