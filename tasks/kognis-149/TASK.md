# TASK kognis-149: ИИ: промпт с точной структурой ответа (R3: 22% проверок из-за несовпадения со схемой)

- **Тип:** standard · **Приоритет:** P2 · **Автор:** jusk-one · **Дата:** 2026-09-29

## 1. Цель
Реальная модель не соблюдает `response_format json_schema`: структура плавает (name вместо title, quotes-объекты,
нет description, дисклеймер в summary). Промпт и повтор должны вести модель к точной структуре. Цель:
json_schema ≥ 90 % первых ответов на реальной модели (проверяет техответственный: `just ai-eval --provider env --direction all`).

## 2. Границы
- **Входит:** SYSTEM_PROMPT с образцом JSON и правилами полей; без требования дисклеймера; повтор с ответом
  модели и списком ошибок валидации (путь + суть, без текстов записей); ATTEMPTS = 2.
- **Не входит:** ослабление схемы (`extra="forbid"` остаётся), «угадывание» полей, реальный прогон.
- **Затрагиваемые модули:** `src/kognis/analysis`.

## 2a. Область влияния
- **Модули:** `analysis` (`_app.py` промпт и повтор, `_domain.py` ошибки разбора) · **Публичные интерфейсы:** нет
- **Данные:** нет · **Что может сломаться:** тесты анализа, `just ai-eval` (те же промпты)
- **Проверки совместимости:** `tests/analysis`, `just verify` · **ADR / миграция:** нет

## 3. Критерии приёмки
| # | Критерий | Как проверить |
|---|---|---|
| AC1 | Промпт содержит образец, совпадающий по ключам с `AnalysisResult.model_json_schema()` | `tests/analysis/test_analysis.py::test_prompt_example_matches_schema` |
| AC2 | При невалидном первом ответе второй запрос содержит ошибки валидации и предыдущий ответ; валидный второй сохраняется | `::test_retry_sends_errors_and_previous_answer` |
| AC3 | Два невалидных ответа → `AnalysisFailedError` с понятным текстом (502) | `::test_two_invalid_answers_give_clear_error` |
| AC4 | В summary дисклеймер не требуется; DISCLAIMER показывает приложение (Shell.tsx) | `::test_prompt_does_not_ask_for_disclaimer` |

## 4. Ограничения
Ошибки валидации не содержат входных значений (тексты записей не попадают в повторный запрос и логи).
