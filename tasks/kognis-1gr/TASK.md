# TASK kognis-1gr: ИИ-провайдер: адаптер, фейк и OpenAI-совместимый клиент

- **Тип:** standard · **Приоритет:** P2 · **Автор:** jusk-one (техответственный, ночное делегирование) · **Дата:** 2026-09-29
- Решения, на которые опирается задача: `docs/DECISIONS-NIGHT.md`, ADR в `docs/adr/`.

## 1. Цель
Приложение обращается к языковой модели через один интерфейс, провайдер меняется настройкой.

## 2. Границы
- **Входит:** модуль ai: протокол AiProvider, FakeProvider (детерминированный), OpenAICompatibleProvider (httpx, env KOGNIS_AI_*; таймауты, повтор при 429/5xx, ключ не логируется), выбор провайдера конфигурацией; тесты клиента на подменённом HTTP (httpx.MockTransport).
- **Не входит:** реальный вызов провайдера с ключом (утром, R3), Anthropic-провайдер.

## 2a. Область влияния
- **Модули:** ai · **Данные:** нет
- **Что может сломаться:** вход и записи (U1), изоляция данных пользователей — регрессионные тесты должны остаться зелёными
