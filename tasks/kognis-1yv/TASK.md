# TASK kognis-1yv: Даты: часовой пояс пользователя — единый источник «сегодня»

- **Тип:** standard · **Приоритет:** P1 · **Автор:** jusk-one (техответственный) · **Дата:** 2026-09-29

## 1. Цель
Записи, итоги дня, серии, квесты и периоды анализа считаются по одному и тому же «сегодня» пользователя —
независимо от часового пояса сервера и браузера. Сейчас сервер берёт Europe/Moscow, фронтенд — пояс браузера:
с 00:00 до 03:00 МСК при UTC-браузере записи выпадают из периода анализа (падает CI: test_analysis_screen при TZ=UTC).

## 2. Границы
- **Входит:** часовой пояс в профиле пользователя (IANA; при регистрации — из браузера
  `Intl.DateTimeFormat().resolvedOptions().timeZone`, по умолчанию Europe/Moscow; смена в профиле), сервер
  вычисляет «сегодня» по поясу пользователя во всех сценариях (сейчас `local_today()` с DEFAULT_TZ), `/api/me`
  отдаёт `today`, фронтенд берёт даты по умолчанию и периоды от него, а не от `new Date()`; миграция.
- **Не входит:** перенос уже сохранённых дат.

## 2a. Область влияния
- **Модули:** users, web, frontend · **Данные:** поле timezone у пользователя (миграция)
- **Что может сломаться:** серии, начисление XP по дням, квизы «раз в день», периоды анализа — регрессия покрыта тестами
