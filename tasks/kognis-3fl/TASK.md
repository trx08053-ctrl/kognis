# TASK kognis-3fl: ИИ: набор примеров и оценка качества разбора на реальной модели (R3)

- **Тип:** standard · **Приоритет:** P0 · **Автор:** jusk-one (техответственный, приёмка продукта) · **Дата:** 2026-09-29

## 1. Цель
Главная ценность Kognis — разбор записей по направлениям психологии — проверена только на заглушке (риск R3
потерялся). Нужен воспроизводимый способ оценивать качество разбора на реальной модели и после каждой правки
промптов.

## 2. Границы
- **Входит:** `evals/ai/cases/*.json` — 10–12 примеров периода дневника (записи + итоги дня), разные ситуации:
  тревога на работе, конфликт в семье, прокрастинация, одиночество, хорошая неделя, мало данных (1–2 записи),
  смешанные языки, кризисный сигнал; у каждого — ожидаемые свойства ответа. `scripts/ai_eval.py` +
  `just ai-eval [--provider fake|env] [--direction …]`: прогон через `AnalysisService`/промпты приложения,
  автоматические проверки на каждый ответ: валидный JSON по схеме; паттерны опираются на реальные записи
  (id существуют, цитаты — подстроки текстов); ответ по-русски; нет диагнозов и назначений лекарств (список
  запрещённых формулировок); уточняющие вопросы при малых данных; кризис → поддерживающий ответ без
  паттернов; время ответа. Отчёт — таблица по примерам + `evals/ai/results.jsonl` (модель, дата, доля
  пройденных проверок). `AiError` называет категорию причины (адрес не найден, таймаут, HTTP-код) без ключа.
- **Не входит:** реальный прогон (его делает техответственный: в песочнице агента нет ключа), смена модели.

## 2a. Область влияния
- **Модули:** ai (тексты ошибок), analysis (без изменения поведения), evals, scripts · **Данные:** нет

## 3. Критерии приёмки
| # | Критерий | Как проверить |
|---|---|---|
| AC1 | `just ai-eval --provider fake` проходит все примеры и пишет отчёт; сломанный ответ фейка (невалидный JSON, выдуманная цитата, диагноз) даёт провал нужной проверки | приёмочный тест `@pytest.mark.acceptance("kognis-3fl", "AC1")` |
| AC2 | Кризисный пример: ответ без паттернов, с контактами помощи — проверка это различает | приёмочный тест `@pytest.mark.acceptance("kognis-3fl", "AC2")` |
| AC3 | `AiError` для DNS/таймаута/HTTP 401/5xx сообщает категорию причины и не содержит ключ | приёмочный тест `@pytest.mark.acceptance("kognis-3fl", "AC3")` |
| AC4 | Реальный прогон на DeepSeek — выполняет техответственный, итог записывается в R3 ARCHITECTURE §8 | ревью |
