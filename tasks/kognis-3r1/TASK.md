# TASK kognis-3r1: Мотивация 2.0 (1/4): ADR, серия с заморозками, выходными и восстановлением, недельная цель

- **Тип:** risky  · **Приоритет:** P2  · **Бюджет:** $8  · **Автор:** jusk-one  · **Дата:** 2026-09-30

## 1. Цель
Серия дней не наказывает за пропуск: запас заморозок, выходные дни по выбору, восстановление обрыва короткой
записью «что помешало» и недельная цель. На экране главное — «дней с дневником за 30» и «всего дней», а не «0».

## 2. Границы
- **Входит:** ADR 0006 (Proposed), новая модель серии (чистые функции в `_domain`), таблицы `gameplay_settings` и
  `streak_recoveries`, `PUT /api/progress/settings`, `POST /api/progress/recovery`, расширение `GET /api/progress`,
  недельная цель с бонусом XP, экран прогресса и настройки в интерфейсе, словари, миграция 0016.
- **Не входит:** баланс XP и достижения (kognis-0a8), герои, соревнования; принятие ADR (человек); вынос старого текста.
- **Затрагиваемые модули:** `gameplay` (`docs/modules/gameplay.md`), `web`, frontend.

## 2a. Область влияния
- **Модули:** `src/kognis/gameplay`, `src/kognis/web/_progress.py`, `frontend/src/components/Progress.tsx`, `Shell.tsx`, `api.ts`, `i18n/ru.ts`.
- **Публичные интерфейсы:** `ProgressOut` + поля (`days_30`, `days_total`, `best_streak`, `freezes`, `recovery`, `weekly_goal`, `weekend_days`); новые `PUT /api/progress/settings`, `POST /api/progress/recovery`.
- **Данные:** `gameplay_settings(owner_id PK, weekend_days, weekly_goal, rules_from)`, `streak_recoveries(owner_id, broken_on, note, created_at)`; XP-события вида `weekly_goal`.
- **Что может сломаться:** серии существующих пользователей; тесты заморозки одной на ISO-неделю; достижения по серии.
- **Проверки совместимости:** `tests/gameplay`, `tests/web/test_gameplay.py`, `tests/security/test_idor.py`, миграционный тест.
- **Нужны ADR / миграция:** ADR 0006; миграция 0016 (expand).
- **Решения человека:** нет.

## 2b. Эволюция
- **Схема:** 0015 → 0016: две новые таблицы; существующим пользователям (есть `xp_events`) — строка настроек с `rules_from` = дата миграции.
- **Совместимость:** expand; до `rules_from` действует прежнее правило (одна заморозка на ISO-неделю, бесплатно), с неё — запас. Серия на момент перехода не уменьшается.
- **Проверка на данных прошлой версии:** тест `@pytest.mark.migration` со старой историей (AC4).
- **Восстановление:** `downgrade` удаляет таблицы.
