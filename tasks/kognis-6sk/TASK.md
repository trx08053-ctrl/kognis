# TASK kognis-6sk: Лендинг на главной для гостей: преимущества, графики, истории, статьи

- **Тип:** standard  · **Приоритет:** P2  · **Бюджет:** — / 3 ч  · **Автор:** jusk-one  · **Дата:** 2026-09-29

## 1. Цель
Гость, открывший главную страницу, видит не голую форму входа, а лендинг: что такое Kognis, его преимущества,
как он помогает двигаться к психическому благополучию (графики, истории, статьи) и понятный путь к регистрации.

## 2. Границы
- **Входит:** страница `/` для гостя (hero, преимущества, интерактивное демо разбора, графики динамики,
  истории, статьи, FAQ, призыв к действию), вход/регистрация на `/login` (`/login?mode=register`),
  фото (сгенерированы локально, webp), анимации с учётом `prefers-reduced-motion`, светлая/тёмная тема.
- **Не входит:** CMS/бэкенд статей, реальные отзывы и статистика (истории и графики помечены как примеры),
  изменения API и публичных маршрутов.
- **Затрагиваемые модули:** `frontend/` (только интерфейс).

## 2a. Область влияния
- **Модули:** `frontend/src` (App, новая страница `pages/LandingPage.tsx`, `pages/landing/*`, AuthPage — режим из URL)

## 4. Ограничения
Без новых зависимостей (React, Tailwind, Recharts уже есть). Истории и цифры на графиках — иллюстрации, это указано
на странице; дисклеймер «не медицинская помощь, кризис — 112» виден на лендинге. Фото без людей-реальных персон.
