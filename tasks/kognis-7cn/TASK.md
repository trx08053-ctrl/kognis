# TASK kognis-7cn: Итог дня: самочувствие, настроение, рефлексия

- **Тип:** standard · **Приоритет:** P2 · **Автор:** jusk-one (техответственный, ночное делегирование) · **Дата:** 2026-09-29
- Решения, на которые опирается задача: `docs/DECISIONS-NIGHT.md`, ADR в `docs/adr/`.

## 1. Цель
В конце дня пользователь оценивает самочувствие и настроение и пишет короткую рефлексию; видит историю оценок.

## 2. Границы
- **Входит:** модуль diary: итог дня (шкалы 1–10 самочувствие и настроение, рефлексия, дата; один на день, можно исправить); API; экран «Итог дня» и история в интерфейсе.
- **Не входит:** графики (Advanced — задача интерфейса), XP (игровое ядро).

## 2a. Область влияния
- **Модули:** diary, web, frontend · **Данные:** новая таблица day_reviews (миграция)
- **Что может сломаться:** вход и записи (U1), изоляция данных пользователей — регрессионные тесты должны остаться зелёными

## 3. Критерии приёмки
| # | Критерий | Как проверить |
|---|---|---|
| AC1 | Пользователь сохраняет итог дня со шкалами 1–10 и рефлексией; повторное сохранение за ту же дату обновляет итог, а не создаёт второй | приёмочный тест `@pytest.mark.acceptance("kognis-7cn", "AC1")` |
| AC2 | Значения вне 1–10 отклоняются с понятной ошибкой в интерфейсе | приёмочный тест `@pytest.mark.acceptance("kognis-7cn", "AC2")` |
| AC3 | История итогов видна только владельцу | приёмочный тест `@pytest.mark.acceptance("kognis-7cn", "AC3")` |
| AC4 | Нет регрессий, интерфейс проверен глазами (`just shot`) и axe | `just verify` |
