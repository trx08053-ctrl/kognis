# TASK kognis-99x: Квесты, челленджи и квизы-рефлексии

- **Тип:** standard · **Приоритет:** P2 · **Автор:** jusk-one (техответственный, ночное делегирование) · **Дата:** 2026-09-29
- Решения, на которые опирается задача: `docs/DECISIONS-NIGHT.md`, ADR в `docs/adr/`.

## 1. Цель
Проблемы, найденные анализом, превращаются в игровые схемы решения: квесты из маленьких шагов, челленджи и квизы-рефлексии; прогресс сохраняется.

## 2. Границы
- **Входит:** gameplay: библиотека квестов (данные-конфигурация, 5–8 квестов по направлениям), квесты из предложений анализа (оркестрация в web), шаги с отметкой выполнения, челленджи на N дней, квизы-рефлексии с XP; экран «Квесты».
- **Не входит:** таблица лидеров, соцфункции.

## 2a. Область влияния
- **Модули:** gameplay, web, frontend · **Данные:** таблицы квестов и прогресса
- **Что может сломаться:** вход и записи (U1), изоляция данных пользователей — регрессионные тесты должны остаться зелёными

## 3. Критерии приёмки
| # | Критерий | Как проверить |
|---|---|---|
| AC1 | Пользователь принимает квест из библиотеки или из результата анализа; шаги отмечаются, прогресс сохраняется между сеансами | приёмочный тест `@pytest.mark.acceptance("kognis-99x", "AC1")` |
| AC2 | Шаг квеста +15 XP, завершение квеста +50 XP; повторная отметка шага XP не даёт | приёмочный тест `@pytest.mark.acceptance("kognis-99x", "AC2")` |
| AC3 | Квиз-рефлексия: ответы сохраняются, +10 XP, не чаще одного раза в день на квиз | приёмочный тест `@pytest.mark.acceptance("kognis-99x", "AC3")` |
| AC4 | Нет регрессий, интерфейс проверен глазами (`just shot`) и axe | `just verify` |
