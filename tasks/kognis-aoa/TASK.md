# TASK kognis-aoa: Навигация — логотип ведёт на главную страницу сайта для вошедшего

- **Тип:** standard  · **Приоритет:** P2  · **Бюджет:** $8  · **Автор:** jusk-one  · **Дата:** 2026-09-30

## 1. Цель
Вошедший пользователь может вернуться на главную страницу сайта (лендинг): логотип в шапке — ссылка на неё,
оттуда одной кнопкой — обратно в дневник. Для гостя `/` по-прежнему лендинг.

## 2. Границы
- **Входит:** ссылка-логотип в `Shell`; маршрут `/welcome` для вошедшего; `LandingPage signedIn` (вместо форм и
  кнопок входа — «Открыть дневник»); новый текст через словарь `t()`.
- **Не входит:** вынос старого текста лендинга в словари, изменения бэкенда.
- **Затрагиваемые модули:** `frontend` (Shell, App, LandingPage, i18n/ru).

## 2a. Область влияния
- **Модули:** `frontend/src` (Shell, App, LandingPage, i18n/ru.ts).
- **Публичные интерфейсы:** нет (новый клиентский маршрут `/welcome`; сервер отдаёт SPA как для остальных путей).
- **Данные:** нет.
- **Что может сломаться:** e2e лендинга для гостя; тесты шапки.
- **Проверки совместимости:** e2e лендинга, vitest страниц, `just verify`.
- **Нужны ADR / миграция:** нет.
- **Решения человека:** описание задачи в bd (2026-09-30, владелец).

## 3. Критерии приёмки
| # | Критерий | Как проверить |
|---|---|---|
| AC1 | Вошедший кликом по логотипу попадает на лендинг и одной кнопкой возвращается в дневник | `tests/e2e/test_logo_nav.py` |
| AC2 | У гостя поведение `/` не изменилось | `tests/e2e/test_logo_nav.py`, `tests/e2e/test_landing.py` |
| AC3 | На лендинге у вошедшего нет форм входа/регистрации | vitest `pages.test.tsx` через `tests/web/test_i18n_frontend.py` |

## 4. Ограничения
Доступность: ссылка с понятным именем (`aria-label`), видимый фокус. Новый текст — только через `t()`.
