# TASK kognis-cdu: Кризисные сигналы в рефлексии итога дня + отметка XP/квестов через allows_rewards (TD-4)

- **Тип:** standard · **Приоритет:** P2 · **Автор:** jusk-one (ночное делегирование) · **Дата:** 2026-09-29
- Опора: D5 (`docs/DECISIONS-NIGHT.md`), запись TD-4 в `docs/TECH_DEBT.md`, карточка `docs/modules/safety.md`.
- Постановка в bd пустая (только название); границы ниже выведены из TD-4 и названия.

## 1. Цель
Человек, написавший кризисную фразу в рефлексии «Итога дня», получает блок помощи, как и при записи в дневник, и не получает за такой итог XP.

## 2. Границы
- **Входит:** проверка текста рефлексии итога дня детектором `safety`; блок помощи в ответе `PUT /api/day-reviews/{date}`; начисление XP за итог (и за запись) только при `Assessment.allows_rewards`.
- **Не входит:** новые фразы детектора, ИИ-детектор, хранение флага кризиса у итога дня (миграции нет), квесты (модуля ещё нет — `allows_rewards` станет общим условием), отзыв уже начисленного XP.

## 2a. Область влияния
- **Модули:** `web` (`src/kognis/web/_app.py`: ответ итога дня, условие начисления); `safety` — без изменений.
- **Публичные интерфейсы:** `DayReviewOut` получает необязательное поле `help` (аддитивно; клиенты N-1 его игнорируют).
- **Данные:** нет. **ADR / миграция:** нет.
- **Что может сломаться:** сохранение итога дня, XP за итог (kognis-50k), запись в дневник с кризисом.
- **Проверки совместимости:** `tests/web/test_day_reviews.py`, `tests/web/test_gameplay.py`.
