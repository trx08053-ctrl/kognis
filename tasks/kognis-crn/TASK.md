# TASK kognis-crn: Мотивация 2.0 (4/4): искры, квест дня, «В этот день», мозаика настроения

- **Тип:** standard  · **Приоритет:** P2  · **Бюджет:** $8 / 8 ч  · **Автор:** jusk-one  · **Дата:** 2026-10-01

## 1. Цель
Валюта «Искры» награждает регулярность и завершённые квесты и тратится только на косметику (спутник, темы
дневника, дополнительная заморозка). Ежедневный квест — выбор 1 из 3 лёгких без штрафа за невыполнение.
«Хранитель архива» показывает свои записи год/месяц назад и мозаику настроения за год — прогресс и аналитика
за искры не продаются.

## 2. Границы
- **Входит:** домен искр `gameplay/_sparks.py` (начисления: недельная цель, уровни достижений, квесты; каталог
  товаров — данные), таблицы `spark_events`, `spark_purchases`, `daily_picks` (миграция 0019), покупка
  заморозки (+1 к запасу при капе `FREEZE_STOCK_MAX`), ежедневный квест 1 из 3 (данные, детерминированный
  выбор по дате), недельная рекомендация квеста от наставника (существующий accept), маршруты
  `/api/sparks*`, `/api/daily-quest`, `/api/archive/*` («В этот день» и мозаика), фронтенд: раздел искр
  (магазин косметики), квест дня на странице квестов, страница архива, аксессуары в SVG спутника, словари ru.
- **Не входит:** соц. механики, продажа прогресса/разборов/аналитики, ИИ-контент, «выносы» старого текста
  (i18n 3–6 отложены владельцем), анимации конфетти.
- **Затрагиваемые модули:** `src/kognis/gameplay` (+`_sparks.py`, `_daily.py`, правки `_app.py`, `_quests_app.py`,
  `_streak.py`, `_infra.py`), `src/kognis/web` (+`_sparks.py`, `_archive.py`, регистрация в `_app.py`),
  `src/kognis/diary` и `analysis` — только чтение через публичный API, `frontend/` (страницы, api.ts, ru.ts).

## 2b. Эволюция
- **Схема:** 0018 → 0019: +`spark_events` (owner_id, kind, ref, amount, day, created_at; unique owner+kind+ref),
  +`spark_purchases` (owner_id, item, ref, price, created_at; unique owner+item+ref), +`daily_picks`
  (owner_id, day, code, done_on; unique owner+day). Существующие данные не преобразуются.
- **Совместимость:** expand. **Проверка:** тест миграции 0019 на данных 0018 (upgrade → сервис работает →
  downgrade удаляет только новые таблицы). **Восстановление:** откат миграции удаляет только новые таблицы.
- **Потребители:** искры читаются собственным API; баланс вычисляется суммой журнала (как серия — из событий).

## 4. Ограничения
Принципы ADR 0006 обязательны: валюта не продаёт прогресс/разборы/аналитику; запас заморозок ≤ 2 всегда;
никакой игровой механики рядом с кризисным контентом (флаг `crisis` — компонент искр не рендерит);
все тексты — словари, ошибки — коды; IDOR-тест на каждый новый маршрут; ввод — схемами с ограничениями;
конкурентность покупок — транзакция с проверкой баланса (без отрицательного баланса).

## 8. Решения
- Баланс искр вычисляется суммой журнала `spark_events` (не хранится) — как серия из дат активности.
- Косметика идемпотентна по unique(owner+item+ref): повторная покупка уже купленного → 409 `sparks.owned`,
  без списания; заморозка — расходник с ref = ISO-неделя покупки (не чаще раза в неделю, кап запаса ≤ 2).
- «В этот день» — календарные юбилеи (год назад = та же дата прошлого года, 29.02 → 28.02; месяц назад =
  тот же день предыдущего календарного месяца с клампом к его длине), а не «365/30 дней». Отдаются только
  `plain` записи (locked текст всё равно пуст, private расшифровывается только в браузере). Мозаика —
  окно последних 365 дней по `day_reviews.mood`, дни без итога — пустая клетка; «сегодня» в интерфейсе —
  серверное (пояс профиля), как требует конвенция dates.ts.
- Варианты квеста дня — детерминированный выбор 3 из пула по (owner_id, date), выполнение даёт XP через
  `xp_events` (kind `daily_quest`) и искры.
- В каталоге нет позиций без эффекта: темы дневника появятся, когда будут отличаться от системной тёмной
  (ревью 1: товар за искры обязан что-то менять); фоны `bg_stars`/`bg_forest` рисуются за спутником.
