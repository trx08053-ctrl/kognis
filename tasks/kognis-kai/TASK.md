# TASK kognis-kai: ИИ-анализ периода по направлениям психологии

- **Тип:** risky · **Приоритет:** P2 · **Автор:** jusk-one (техответственный, ночное делегирование) · **Дата:** 2026-09-29
- Решения, на которые опирается задача: `docs/DECISIONS-NIGHT.md`, ADR в `docs/adr/`.

## 1. Цель
Пользователь выбирает период и направление психологии и получает резюме, динамику настроения, поведенческие паттерны и уточняющие вопросы.

## 2. Границы
- **Входит:** модуль analysis (D7): направления как данные (КПТ, ACT, схема-терапия, позитивная психология, поведенческая активация), согласие на передачу записей на каждый анализ, строгий JSON-ответ (pydantic) с паттернами и опорами на записи, уточняющие вопросы и ответы на них (продолжение анализа), динамика настроения локально, сохранение анализов; access.can_use(user, 'ai_analysis'); safety: при кризисных записях — поддерживающий ответ без паттернов; экран анализа (простой: одна кнопка «Разобрать неделю»; Advanced: период, направление).
- **Не входит:** приватные записи (не передаются никогда), квесты (следующая задача).

## 2a. Область влияния
- **Модули:** analysis, access, web, frontend · **Данные:** таблица analyses
- **Что может сломаться:** вход и записи (U1), изоляция данных пользователей — регрессионные тесты должны остаться зелёными

## 3. Критерии приёмки
| # | Критерий | Как проверить |
|---|---|---|
| AC1 | Без согласия пользователя записи не передаются провайдеру (проверка на фейковом провайдере: ноль вызовов) | приёмочный тест `@pytest.mark.acceptance("kognis-kai", "AC1")` |
| AC2 | С согласием анализ за период возвращает резюме, паттерны с опорой на записи, уточняющие вопросы и сохраняется в истории | приёмочный тест `@pytest.mark.acceptance("kognis-kai", "AC2")` |
| AC3 | Невалидный ответ модели не ломает приложение: понятная ошибка и повтор | приёмочный тест `@pytest.mark.acceptance("kognis-kai", "AC3")` |
| AC4 | При кризисной записи в периоде анализ возвращает поддерживающее сообщение и контакты помощи, без паттернов | приёмочный тест `@pytest.mark.acceptance("kognis-kai", "AC4")` |
| AC5 | Динамика настроения за период считается из итогов дня без ИИ | приёмочный тест `@pytest.mark.acceptance("kognis-kai", "AC5")` |
| AC6 | Нет регрессий, интерфейс проверен глазами (`just shot`) и axe | `just verify` |
