# TASK kognis-qkh: Разборы ИИ: история, повторное открытие и удаление

- **Тип:** standard  · **Приоритет:** P2  · **Бюджет:** $8  · **Автор:** jusk-one  · **Дата:** 2026-09-30

## 1. Цель
Результат разбора не теряется при уходе со страницы: на странице «Разбор» виден постраничный список сохранённых
разборов, последний открыт по умолчанию, любой прошлый можно открыть целиком или удалить.

## 2. Границы
- **Входит:** `GET /api/analyses` с `limit`/`offset` (следующее смещение — заголовок `X-Next-Cursor`), `created_at`
  в ответе, `DELETE /api/analyses/{id}`, список и удаление на странице «Разбор», показ ответов-уточнений.
- **Не входит:** память между разборами, автопериод, лимиты (kognis-sky); вынос старого текста в словари (i18n 3–6);
  показ контактов помощи в кризисном разборе из истории (сервер их не хранит).
- **Затрагиваемые модули:** `analysis` (`docs/modules/analysis.md`), `web`, frontend.

## 2a. Область влияния
- **Модули:** `src/kognis/analysis` (репозиторий, сервис), `src/kognis/web/_analysis.py`, `frontend/src/pages/AnalysisPage.tsx`, `api.ts`, словарь `ru.ts`.
- **Публичные интерфейсы:** `GET /api/analyses` получает необязательные `limit`/`offset` (без них — первая страница 30; раньше отдавал всё); `AnalysisOut` +`created_at`; новый `DELETE /api/analyses/{id}`. Потребитель — только наш фронтенд.
- **Данные:** нет (колонка `created_at` уже есть). Удаление физическое; у ответов-продолжений `parent_id` остаётся без родителя (нет FK) — продолжения самодостаточны.
- **Что может сломаться:** ответ на вопросы (parent), квесты из идей разбора (`source_ref` — строка, не зависит).
- **Проверки совместимости:** существующие тесты `tests/analysis`, `tests/security/test_idor.py`, e2e разбора.
- **Нужны ADR / миграция:** нет.
- **Решения человека:** нет.
