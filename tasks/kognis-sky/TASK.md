# TASK kognis-sky: Разборы ИИ: преемственность (память), автоматический период, лимиты и бюджет токенов

- **Тип:** risky  · **Приоритет:** P2  · **Бюджет:** $8  · **Автор:** jusk-one  · **Дата:** 2026-09-30

## 1. Цель
Разбор не гоняет по кругу старые записи: период по умолчанию идёт от прошлого разбора, объём текста ограничен,
дубли отсекаются, а модель получает сжатую «память» пользователя и итог прошлого разбора. Человек видит и
может очистить, что ИИ о нём помнит.

## 2. Границы
- **Входит:** период по умолчанию (`GET /api/analyses/period`), лимит 31 день, бюджет текста, `409 analysis.duplicate`,
  память (таблица `analysis_memory`, `GET/DELETE /api/analyses/memory`), поля `changes`/`memory` в ответе модели,
  блок «Что изменилось» и «Что ИИ помнит обо мне» в интерфейсе, пример в ai-eval, ADR (Proposed).
- **Не входит:** прогон ai-eval на реальной модели и принятие ADR (человек); удаление аккаунта (в продукте его нет);
  вынос старого текста в словари.
- **Затрагиваемые модули:** `analysis` (`docs/modules/analysis.md`), `web`, frontend, `evals/ai`.

## 2a. Область влияния
- **Модули:** `src/kognis/analysis`, `src/kognis/web/_analysis.py`, `frontend/src/pages/AnalysisPage.tsx`, `api.ts`, `i18n/ru.ts`, `evals/ai`.
- **Публичные интерфейсы:** `MAX_PERIOD_DAYS` 92 → 31 (потребитель — наш фронтенд); `AnalysisOut` +`changes`; новые `GET /api/analyses/period`, `GET|DELETE /api/analyses/memory`; `POST /api/analyses` может вернуть 409.
- **Данные:** новая таблица `analysis_memory` (владелец analysis), миграция expand; `result` JSON получает необязательное `changes`.
- **Что может сломаться:** старые разборы (валидация без новых полей — поля с умолчаниями), продолжение по ответам, тесты периода 92 дня.
- **Проверки совместимости:** `tests/analysis`, `tests/security/test_idor.py`, e2e разбора, миграционный тест.
- **Нужны ADR / миграция:** ADR 0005 (память ИИ, Proposed); миграция 0015 expand.
- **Решения человека:** нет.

## 2b. Эволюция
- **Схема:** +таблица `analysis_memory(owner_id PK, digest, updated_at)`; существующие данные не меняются.
- **Совместимость:** expand; старый образ таблицу не использует. Откат — `downgrade` удаляет таблицу.
- **Проверка на данных прошлой версии:** старый `result` без `changes` читается (тест).

## 2c. Угрозы
| Угроза | Мера | Тест |
|---|---|---|
| Чужая память читается/очищается | владелец в условии запроса; маршруты без id | idor память |
| Цитаты записей под замком в памяти | в анализ уходят только `plain`; промпт запрещает цитаты; память ≤ 2000 | тест сообщений |

## 4. Ограничения
Новый текст — через `t()` и коды ошибок. Новых зависимостей нет. Добавка к запросу ≤ ~3 500 символов.

## 5. Риски

## 8. Решения
ADR 0005 (Proposed). Память очищается кнопкой и когда у пользователя не осталось разборов. Дубль — только среди разборов
со статусом `done` без `parent_id`.
