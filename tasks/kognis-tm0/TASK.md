# TASK kognis-tm0: Визуальный дизайн: навигация, карточки, иконки, мобильная вёрстка

- **Тип:** standard · **Приоритет:** P2 · **Автор:** jusk-one (техответственный) · **Дата:** 2026-09-29

## 1. Цель
Интерфейс выглядит как современное приложение-дневник: спокойный, дружелюбный, понятный с первого взгляда,
удобный на телефоне. Сейчас функционально полный, но визуально «инженерный» (ссылки-подчёркивания, одна длинная
страница, серые полосы прогресса, формы без иерархии).

## 2. Границы
- **Входит:** навигация — вкладки/боковое меню на десктопе и нижняя панель на телефоне (Дневник, Итог дня, Разбор,
  Квесты, Профиль/Достижения) с иконками (inline SVG, без новых зависимостей); шапка с аватаром-инициалом, уровнем
  и серией (огонёк); главная — «сегодня»: приветствие по времени суток, карточка итога дня, кнопка «Записать»,
  последние записи; форма записи — эмоции чипами (выбор из словаря + своя), теги чипами, режим защиты —
  сегментированный переключатель «Обычная / Под замком / Приватная» с пояснением; прогресс — скруглённая шкала с
  акцентным цветом, уровни и достижения — бейджи; квесты — карточки с прогрессом шагов; палитра на CSS-переменных
  (светлая и тёмная, контраст AA), единые отступы и радиусы; мобильная вёрстка 375 px без горизонтальной прокрутки;
  онбординг — один раз, закрытие сохраняется.
- **Не входит:** новые функции и API, анимации сложнее переходов CSS.

## 2a. Область влияния
