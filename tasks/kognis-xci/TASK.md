# TASK kognis-xci: Отключить кризисный детектор до мультиязычной версии; страховка в промпте; grounding ai-eval по всем данным

- **Тип:** risky · **Приоритет:** P1 · **Бюджет:** $8 · **Автор:** jusk-one · **Дата:** 2026-09-30

## 1. Цель
Решение владельца продукта (2026-09-30): кризисный детектор пока отключён полностью — продукт станет мультиязычным
(ru/en/es/fr), а фразы и контакты помощи зависят от языка и страны; без проверки носителем и юристом детектор даёт
ложное чувство защищённости. Вместо него — страховка в промпте анализа и честные тексты интерфейса. Дополнительно:
проверка grounding в `scripts/ai_eval.py` сверяет цитаты со всем, что отправлено модели.

## 2. Границы
- **Входит:** настройка `KOGNIS_CRISIS_DETECTOR` (on/off, по умолчанию off) в `safety`; инструкция про угрозу жизни в
  промпте анализа; тексты лендинга; `scripts/ai_eval.py` и `evals/ai/README.md`; README/RUNBOOK/ARCHITECTURE/карточка safety;
  задача bd на включение детектора по языкам (kognis-fvn).
- **Не входит:** удаление кода детектора, фраз, контактов и колонки `entries.crisis` (включение = `on` без правок кода);
  сам мультиязычный детектор (kognis-fvn); экран анализа со статусом crisis остаётся для режима on.
- **Затрагиваемые модули:** `src/kognis/safety`, `src/kognis/analysis`, `frontend` (лендинг), `scripts/ai_eval.py`.

## 2a. Область влияния
- **Модули:** `safety` (`_infra.py` чтение настройки, `_app.py::check_text`, `__init__` экспортирует `crisis_detector_enabled`), `analysis` (`SAFETY_CLAUSE` в промпте), `web` не меняется (получает эффект через `check_text`), фронтенд `pages/landing/content.ts`.
- **Публичные интерфейсы:** `kognis.safety.crisis_detector_enabled` (новый), потребитель — `scripts/ai_eval.py`; контракт API не меняется.
- **Данные:** нет (колонка `entries.crisis` сохранена; ранее помеченные записи по-прежнему дают статус crisis при анализе).
- **Что может сломаться:** тесты, полагавшиеся на детектор по умолчанию (переведены на явный `crisis_on`); `just ai-eval` для кризисных примеров.
- **Проверки совместимости:** `tests/safety`, `tests/web`, `tests/analysis`, `tests/ai`, e2e, `just verify`.
- **Нужны ADR / миграция:** нет.
- **Решения человека:** 2026-09-30, владелец продукта: детектор отключить (см. описание kognis-xci); правка `scripts/ai_eval.py` входит в постановку задачи; `tests/conftest.py` — общие фикстуры `crisis_on` / автоотключение детектора в тестах.

## 6. Неизвестные, гипотезы и эксперименты
Качество совета реальной модели на кризисных примерах не проверено в этой сессии (нет доступа к модели):
запуск `KOGNIS_AI_*=… just ai-eval --provider env --direction all` — за техответственным.

## 8. Решения
Режим читается только через `crisis_detector_enabled()`; `check_text` при off возвращает «нет сигнала». Ранее помеченные
`entries.crisis` записи по-прежнему приводят к статусу crisis при анализе (консервативно; данные не трогаем).
