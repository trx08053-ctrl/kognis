# TASK kognis-yaj: Hardening: ограничение входа, заголовки безопасности, приватность логов

- **Тип:** risky · **Приоритет:** P2 · **Автор:** jusk-one (техответственный, ночное делегирование) · **Дата:** 2026-09-29
- Решения, на которые опирается задача: `docs/DECISIONS-NIGHT.md`, ADR в `docs/adr/`.

## 1. Цель
Приложение готово к пилоту на сервере: защита от перебора паролей, заголовки безопасности, содержимое записей не утекает в логи.

## 2. Границы
- **Входит:** ограничение попыток входа (по email и IP, в БД), заголовки безопасности (CSP, frame-ancestors, referrer-policy), проверка логов на отсутствие текста записей, RUNBOOK (ключ данных, бэкап, восстановление), just stage зелёный.
- **Не входит:** платёжные функции, внешний мониторинг.

## 2a. Область влияния
- **Модули:** users, web, docs · **Данные:** таблица попыток входа
- **Что может сломаться:** вход и записи (U1), изоляция данных пользователей — регрессионные тесты должны остаться зелёными

| # | Критерий | Как проверить |

| AC3 | Тексты записей не попадают в логи приложения (тест на перехват логов) | приёмочный тест `@pytest.mark.acceptance("kognis-yaj", "AC3")` |
| AC4 | Нет регрессий, интерфейс проверен глазами (`just shot`) и axe | `just verify` |
