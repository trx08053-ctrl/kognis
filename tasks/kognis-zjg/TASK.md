# TASK kognis-zjg: Мотивация 2.0 (3/4): цифровые герои — спутник и наставники

- **Тип:** standard  · **Приоритет:** P2  · **Бюджет:** $8  · **Автор:** jusk-one  · **Дата:** 2026-10-01

## 1. Цель
Спутник растёт по числу дней с дневником (без регресса), приносит «открытку» для рефлексии после итога дня;
наставники по направлениям открываются разбором или квестом и говорят короткую реплику. Принципы дизайна
(bd kognis-zjg): без вины, без награды за объём/тон, без игровой механики рядом с кризисным контентом.

## 2. Границы
- **Входит:** правила героев как данные (`gameplay/_heroes.py`), таблицы `companions`, `companion_postcards` (миграция 0018),
  `GET/PUT /api/companion`, `POST /api/companion/seen`, компонент героев (SVG, светлая/тёмная тема, reduced-motion),
  словари реплик/открыток (ru, ты/вы), показ в дневнике, карточке разбора и квестах.
- **Не входит:** иллюстрации высокого качества, соц. механики, вынос старого текста, ИИ для открыток.
- **Затрагиваемые модули:** `gameplay`, `web`, frontend.

## 2a. Область влияния
- **Модули:** `src/kognis/gameplay` (+ `_heroes.py`), `src/kognis/web/_companion.py`, `frontend/src/components/Heroes.tsx`, страницы Home/Analysis/Quests, `i18n/ru.ts`.
- **Публичные интерфейсы:** новые маршруты `/api/companion*`; существующие не меняются.
- **Данные:** две новые таблицы (expand, без изменения старых); обращение «ты/вы» хранится у спутника (выбор пользователя при знакомстве, меняется там же).
- **Что может сломаться:** главная страница (новый блок), карточка разбора, квесты — тесты страниц.
- **Проверки совместимости:** `just verify`.
- **Нужны ADR / миграция:** миграция 0018; ADR не нужен (продолжение ADR 0006).
- **Решения человека:** нет.

## 2b. Эволюция
- **Схема:** +`companions`, +`companion_postcards`; старые данные не затрагиваются.
- **Совместимость:** expand (новые таблицы). **Проверка:** тест миграции 0018. **Восстановление:** откат миграции удаляет только новые таблицы.

## 8. Решения
- Открытка хранится строкой на день (`for_day` = итог дня, за который принесена); выбор детерминирован (владелец + дата).
- Кризис определяет экран (флаг crisis у записи/итога/разбора): бэкенд реплику отдаёт, компонент на экране с флагом её не рисует.
